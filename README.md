# sts – Website (Variante v3)

Einstieg: `index.html` (Design Component, lädt `support.js`). Muss über einen lokalen Server laufen, z. B. `npx serve .` oder `python3 -m http.server`; Doppelklick auf die Datei reicht nicht.

- `styles.css`, `tokens/` – Farben, Typografie, Abstände
- `fonts/` – Grosa Light/Regular (lizenziert, vor Veröffentlichung Repo-Sichtbarkeit prüfen)
- `assets/` – Logos, Porträt
- `support.js`, `image-slot.js` – Laufzeit

Offen: `impressum.html`, `agb.html`, `datenschutz.html` sind verlinkt, aber noch nicht angelegt.
